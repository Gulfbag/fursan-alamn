# تكامل الذكاء الاصطناعي — جاهزية برمجية لا تفعيل إنتاجي

## ما أضيف

يتضمن `server/ai/assistant.mjs` موصلًا خادميًا إلى واجهة `generateContent` لدى Google Cloud، المعروفة في الوثائق الحالية باسم Gemini Enterprise Agent Platform (سابقًا Vertex AI). يستخدم هوية خدمة عبر ADC، ولا يستعمل API key في المتصفح. يرسل نصوصًا مختارة فقط، ولا يرسل فيديو أو صورًا أو وثائق كاملة، ولا يمنح النموذج أدوات كتابة أو اعتماد أو إغلاق بلاغ.

الموصل **معطل افتراضيًا، وغير مربوط بأي مسار HTTP عام أو شاشة تشغيل حقيقية**. النموذج المعروض في البوابة ينتج مسودة محلية من الحقول، وهو ليس تشغيلًا لنموذج توليدي. الاختبارات تستخدم استجابات محقونة ولا تتصل بخدمة Google الفعلية.

## حدود الأمان

| الضابط البرمجي | ما يتحقق قبل التفعيل الحقيقي |
|---|---|
| تحقق نطاق tenant / contract / site ودور operations أو supervisor | استخراج principal من جلسة SSO موثقة خادميًا؛ لا يقبل من JSON يرسله المتصفح. حقول principal وحدها ليست بديلًا عن التحقق من الرمز والتوقيع والجلسة |
| المصدر معتمد للمعالجة ومحدد النطاق | تنفيذ تصنيف البيانات وتنقيحها واعتماد الغرض والمنطقة ومعالج البيانات؛ علم approvedForAi ليس نظام تصنيف أو تنقيح تلقائيًا |
| مراجع الناتج من معرفات المصادر الفعلية | مراجعة بشرية للمعنى والدقة؛ صحة معرف المصدر لا تثبت صحة كل جملة مولدة |
| الناتج status=draft وreviewRequired=true وactionTaken=false | فصل مسار إنشاء المسودة عن مسار الاعتماد؛ المعتمد شخص مخول، وليس النموذج |
| أحداث audit دون نصوص أو PII | وصل سجل تدقيق دائم محمي، وليس callback اختباريًا أو سجل ذاكرة |
| مهلة اتصال ومخرجات JSON ورفض استجابة مبتورة | حد تكلفة وحصة موزعان، مراقبة أخطاء واستجابة، وسجل نسخ نموذج وتقييم عربي |
| Endpoint إقليمي مقيد بصيغة Google الرسمية | اعتماد المنطقة والنموذج والتحقق من توافرهما فعلًا؛ لا توجد منطقة أو نسخة نموذج مفترضة في الإعداد الحالي |

لا يتم حفظ المسودة تلقائيًا أو تغيير حالة البلاغ أو اتخاذ تصعيد أمني. لا توجد في هذا التسليم مصادقة إنتاجية أو فهرس RAG أو OCR فعلي أو تحليل فيديو فعلي. هذه قدرات مراحل لاحقة، وليست نتائج مثبتة من هذا الموصل.

## تهيئة لاحقة

يهيئ خادم البوابة `createAssistant` ببيانات مشروع ومنطقة ومعرف نموذج **معتمد ومتاح**، وتفعيل مستقل لـ `enabled` و`dataProcessingApproved`، ثم يمرر `principal` الناتج من الهوية الموثقة، وبلاغًا محملًا خادميًا، ومصادر مرخصة وفق العقد والموقع. تستخدم خدمة Cloud Run حساب الخدمة المخصص وفق أقل امتياز. لا ترسل مفاتيح JSON في المستودع أو المحادثة، ولا تفعّل صلاحيات أو موارد جديدة قبل اعتمادها.

تظل حماية الهوية والعزل والتدقيق والحصص مسؤولية طبقة البوابة الحقيقية قبل وصل الموصل. يتطلب طرحه قبول اختبارات ضد تسرب بيانات بين العملاء، ومحاولات حقن تعليمات في المصادر، وأخطاء التلخيص، وحالات انقطاع الاتصال. لا تُستخدم مسوداته كتعليمات ميدانية تلقائية.
